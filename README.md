## 📜 وش اللي مسموح هنا؟ (كل شي حلالك)

المستودع وما فيه تحت أمرك، وبدون أي قيود:

* **السكريبتات والأكواد:** اي كود أو سكريبت تشوفه قدامك، نسخه، تعديله، واستخدامه في مشاريعك متاح للجميع بدون استئذان.
* **الأفكار والتصميم:** الأفكار والملفات محطوطة عشان تستفيد منها وتطورها بالطريقة اللي تعجبك.
* **الصور والخلفيات:** الصور الواقعية والتصميمات المرئية الموجودة بالمستودع حلالك استخدمها وين ما تبغى.
